## 🎯 Цель
Создание макета логики работы автомата со снеками в виде блок-схемы. 

## 📝 Текущий этап работы
На данном этапе мы уточнили ключевые вопросы по взаимодействию с пользователем и разработали макет логики работы автомата в виде блок-схемы (дерева решений).

## 🌳 Логика работы автомата
В основе работы лежит алгоритм с несколькими уровнями сложности и разветвленной логикой в зависимости от ответов пользователя.
